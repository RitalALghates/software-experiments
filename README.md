# software-experiments

A collection of small Python experiments and mini-projects.

## Contents

- `count_words` - count the words in a text
- `factorial` - compute n!
- `is_palindrome` - check whether a string is a palindrome
- `reverse_list` - reverse a list
- `code_input_1.py`, `chatgpt_comment_1.py` - other small exercises

Some files are variants of the same function written with and without AI assistance.

## Run

```bash
python <file>.py
```
